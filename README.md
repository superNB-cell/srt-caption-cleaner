# SRT Caption Cleaner

SRT Caption Cleaner is a local-only subtitle cleanup tool for `.srt` and `.vtt` captions.

It helps with:

- Renumbering cues.
- Cleaning extra spaces.
- Wrapping long caption lines.
- Detecting overlapping cues.
- Flagging very short, very long, or empty captions.
- Exporting cleaned SRT and a quality report.

## Privacy

The tool is a static browser page. Captions are processed locally in the browser. It does not upload, store, or send caption files.

## Demo

Open `index.html` in a browser, paste captions, or load the built-in sample.

## Scope

This is a lightweight cleanup and QA helper. It does not replace professional captioning, legal review, or platform-specific accessibility requirements.
